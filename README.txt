YogaEntspannung — HTML website

Open index.html in a browser, or upload index.html and the assets/ folder to your web hosting document root (usually public_html).

No PHP, database, installation or build step is required. Keep the assets/ folder beside index.html. Includes responsive layout, mobile navigation, yoga detail dialogs, FAQ and a one-minute breathing timer with pause/resume/reset.

Images, CSS and JavaScript are included. Google Fonts load when online, with system font fallbacks. Images are reused from existing workspace assets; verify image usage rights before public release. No domain or hosting deployment is included.
